# csv-report-tool

Превращает «грязные» выгрузки из Excel и 1С в готовый сводный отчёт: один запуск
вместо ручной чистки в Excel.

## Задача, которую решает

У интернет-магазина есть выгрузки продаж за каждый месяц. Они разные: одна в UTF-8,
другая в `cp1251` (так сохраняет русский Excel), даты то `2025-01-08`, то `08.01.2025`, цены то с точкой, то с запятой, где-то дубли и пустые строки. Раньше это собирали руками в Excel — час-полтора в месяц. Теперь это одна команда.

## Быстрый старт

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux / macOS
pip install -r requirements.txt

python main.py sample_data/sales_january.csv sample_data/sales_february.csv sample_data/sales_march.csv -o output/report.xlsx
```

Откроется `output/report.xlsx` с двумя листами: «Сводка» и «Данные».

## Пример: до и после

На тестовых файлах из `sample_data/`:

```
Файлов: 3 | строк на входе: 30 | в отчёте: 25
Кодировки: sales_january.csv: utf-8, sales_february.csv: cp1251, sales_march.csv: utf-8
Отброшено 5 строк (пустых: 2, без количества: 1, без цены: 1, дублей: 1)

Группа                    Заказов    Штук         Выручка    Доля
-----------------------------------------------------------------
Кофе в зёрнах                  10      33     41 256,50 ₽  50.73%
Кофемолка                       5       5     17 000,00 ₽  20.90%
Чай зелёный                     5      17     11 730,00 ₽  14.42%
Чай чёрный                      5      21     11 340,00 ₽  13.94%
-----------------------------------------------------------------
ИТОГО                          25      76     81 326,50 ₽
Средний чек: 3 253,06 ₽
```

Ничего не теряется молча: каждая отброшенная строка посчитана по причине,
и эти цифры попадают в отчёт.

## Что умеет

**Кодировки.** Определяет `utf-8`, `utf-8-sig` (с BOM) и `cp1251` автоматически.
Если файл битый или кодировка известна — можно задать явно через `--encoding`.
При неверной кодировке выдаёт ошибку, а не кракозябры в отчёте.

**Разделители.** Запятая, точка с запятой, таб — определяется по заголовку.

**Заголовки.** Понимает `Дата`/`date`, `Менеджер`/`manager`, `Товар`/`product`,
`Город`/`city`, `Количество`/`Кол-во`/`quantity`, `Цена`/`Стоимость`/`price`.
Лишние колонки не ломают разбор — о них будет сказано в выводе.

**Числа.** `1250.00`, `1250,50`, `1 250,50`, `1.250,50`, `1,250.50`, `1250.00 руб.`,
неразрывные пробелы.

**Даты.** `2025-01-08`, `08.01.2025`, `08/01/2025`.

**Очистка.** Пустые и пробельные строки, дубли (после нормализации пробелов),
строки без даты, количества или цены. Отрицательные и нулевые значения отбрасываются.

**Отчёт.** Excel с форматированием: «Сводка» — итоги, отброшенные строки с причинами,
таблица по группам с долями; «Данные» — очищенные строки с автофильтром.

## Использование

```
python main.py ФАЙЛ [ФАЙЛ ...] [-o ВЫХОД] [-g КОЛОНКА] [--encoding КОДИРОВКА] [--no-console]
```

| Параметр           | Что делает                                                         |
| ------------------ | ------------------------------------------------------------------ |
| `ФАЙЛ ...`         | один или несколько CSV. Маски оболочка раскрывает сама (`*.csv`)   |
| `-o`, `--output`   | куда сохранить файл, по умолчанию `output/report.xlsx`             |
| `-g`, `--group-by` | группировка: `Товар`, `Менеджер`, `Город`, `Дата` или по-английски |
| `--encoding`       | задать кодировку явно (`cp1251`, `utf-8`)                          |
| `--no-console`     | не печатать сводку, только сохранить файл                          |

Коды возврата: `0` — успех, `1` — ошибка в данных, `2` — неверные аргументы.
Это позволяет вставить утилиту в скрипт и проверить результат.

## Что утилита не делает

- Не читает `.xlsx` на входе — только CSV. Конвертация из Excel в CSV занимает
  десять секунд и сохраняет прозрачность: видно, что именно пришло.
- Не соединяет таблицы по ключу и не строит графики.
- Не угадывает смысл колонок: если в файле нет одной из шести обязательных,
  будет ошибка с перечнем отсутствующих.
- Не чинит данные за вас: строки с некорректной датой или ценой отбрасываются
  и подсчитываются, а не додумываются.

## Тесты

```bash
python -m pytest
```

85 тестов: разбор чисел и дат, определение кодировок и разделителей, очистка на
реальных «грязных» данных, агрегация, формат Excel, CLI целиком через subprocess.

Отдельно проверяется то, что легко сломать незаметно: формат ячеек Excel
(деньги с `₽`, доля с `%`), отсутствие мутации входных данных, вывод в консоль
на русской Windows, где `₽` нет в cp1251, раскрытие масок (`sample_data/*.csv`)
и понятные сообщения, когда на вход подали не ту таблицу.

## Структура

```
clean.py            чтение, определение кодировки, очистка, статистика отбросов
report.py           агрегация: заказы, штуки, выручка, доли
output.py           Excel и консольная сводка
main.py             CLI
sample_data/        три «грязных» выгрузки для демо
tests/              85 тестов
```
