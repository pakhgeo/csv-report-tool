# Тестовые данные

Три выгрузки из «1С-подобной» системы интернет-магазина — специально в том виде,
в каком они обычно и приходят от клиента.

| Файл | Что с ним «не так» |
|---|---|
| `sales_january.csv` | почти чистая: UTF-8, запятая как разделитель, ISO-даты, точка в дробях |
| `sales_february.csv` | кодировка **cp1251**, разделитель `;`, даты `ДД.ММ.ГГГГ`, запятая в дробях — типичный экспорт из русского Excel |
| `sales_march.csv` | дубли строк, пустые и пробельные строки, лишние пробелы и табы в полях, смешанные форматы дат, пропущенные количество и цена |

Ожидаемое поведение: пустые и пробельные строки отбрасываются, дубли после
нормализации пробелов схлопываются, строки без количества или цены отбрасываются
с подсчётом в отчёте — а не молча.
